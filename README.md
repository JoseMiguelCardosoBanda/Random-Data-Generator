# React + Vite - Random Data Generator

 To initalize the app use npm run dev

* At first the app will show the following screen.

  ![image](https://github.com/user-attachments/assets/997833f5-298d-473f-b797-01adeb98852a)


* By clicking the lightbulb button, the theme will switch between light and dark mode.

  ![image](https://github.com/user-attachments/assets/1ef84402-fc01-4a6e-9552-eca346d04ed5)


* There are two buttons at the page's bottom, the left one will add 20 more rows to the table, and the right one returns to the page's top.

  ![image](https://github.com/user-attachments/assets/adb12d6b-b2d6-4d06-b8a5-56bd7b1c85f7)

  ![image](https://github.com/user-attachments/assets/76017945-b62c-4522-a2b1-71b764d80680)


* The button at the top, exports all the table's data to an .xls file.
  
  ![image](https://github.com/user-attachments/assets/4ae454f7-759d-4f5d-8b64-fa3e831ee7a1)

* If the chosen region is changed, the table will be cleaned and new data according to the selected region will be generated.
  
  ![image](https://github.com/user-attachments/assets/782393a3-9b74-4050-8603-fa37d3216cfc)
